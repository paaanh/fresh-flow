# End-to-end tests

Thư mục dành cho kiểm thử trình duyệt xuyên suốt web và API. Các kịch bản mục tiêu được liệt kê trong [`../../docs/testing-plan.md`](../../docs/testing-plan.md).

Chưa cấu hình runner E2E trong `apps/web/package.json`; bổ sung framework và script chạy trước khi thêm test tự động tại đây.
